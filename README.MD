# UDCT v2.6.7: L=6 Higgs Hierarchy with Memory Kernel

This repository contains the Python implementation and results for UDCT v2.6.7, focusing on L=6 compact U(1) lattice Monte Carlo simulations with an adaptive Memory Kernel for Higgs hierarchy stabilization studies.

## Contents

- `python/`: Core Python scripts (Monte Carlo + Memory Kernel)
- `figures/`: Generated plots from L=6 simulations
- `data/`: Sample data files (optional)

## Key Features

- L=6 U(1) Lattice Monte Carlo
- Adaptive Memory Kernel with dynamic threshold
- Higgs hierarchy stabilization tests
